=== Value Types

DPM supports the following value types:

[cols="1,1,3", options="header"]
|===
| Type | Example | Description

| Integer
| `42`
| Whole numbers (64-bit signed)

| String
| `"hello"`
| Text data (UTF-8 encoded)

| Boolean
| `true`, `false`
| True/false values

| List
| `(1 2 3)`
| Ordered collections of values

| Nil
| `nil`
| Null/void value
|===

==== Type Coercion

DPM automatically coerces types when appropriate:

[source,lisp]
----
;; Numbers are converted to strings in print
(print 42)  ; => "42"

;; Strings can be concatenated
(concat "The answer is " 42)  ; => "The answer is 42"
----
