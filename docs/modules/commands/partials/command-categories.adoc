=== Command Categories

DPM organizes commands into the following categories:

[cols="1,1,3", frame=none]
|===
| *Category* | *Prefix* | *Purpose*

| Core
| `(print)`, `(+)`, `(*)`
| Basic operations, arithmetic, I/O

| Environment
| `(rust-env-*)`
| System environment variables

| Filesystem
| `(rust-fs-*)`
| File and directory operations

| Path
| `(rust-path-*)`
| Cross-platform path manipulation

| Process
| `(rust-process-*)`
| Execute system commands

| Docker
| `(docker)`
| Docker Compose integration
|===

==== Category Details

**Core Commands**: Basic operations like `print`, `+`, `*`, `concat`, `debug`, `pipe`, and `help`.

**Environment Commands**: Access and modify environment variables with `rust-env-var`, `rust-env-set`, `rust-env-current-dir`, `rust-env-home-dir`, and `rust-env-vars`.

**Filesystem Commands**: File operations including `rust-fs-read-to-string`, `rust-fs-write`, `rust-fs-create-dir`, and `rust-fs-copy`.

**Path Commands**: Cross-platform path manipulation with `rust-path-join`, `rust-path-parent`, `rust-path-filename`, `rust-path-extension`, `rust-path-exists`, `rust-path-is-dir`, and `rust-path-is-file`.

**Process Commands**: Execute external commands with `rust-process-command` and `rust-process-output`.

**Docker Commands**: Docker Compose integration with the `docker` command.
