= Environment Commands
:navtitle: Environment Commands
:description: Commands for working with system environment variables

== Overview

Environment commands provide access to system environment variables and current directory information.

== rust-env-current-dir

Gets the current working directory.

=== Syntax

[source,lisp]
----
(rust-env-current-dir)
----

=== Parameters

None.

=== Return Value

Returns current directory path as string.

=== Examples

[source,lisp]
----
(rust-env-current-dir)  ; => "/home/user/project"
(print "Working in: " (rust-env-current-dir))
----

== rust-env-home-dir

Gets the user's home directory.

=== Syntax

[source,lisp]
----
(rust-env-home-dir)
----

=== Parameters

None.

=== Return Value

Returns home directory path as string.

=== Examples

[source,lisp]
----
(rust-env-home-dir)  ; => "/home/user"
(rust-path-join (rust-env-home-dir) ".config")  ; => "/home/user/.config"
----

== rust-env-var

Gets an environment variable value.

=== Syntax

[source,lisp]
----
(rust-env-var "NAME")
----

=== Parameters

[cols="1,3", frame=none]
|===
| *Parameter* | *Description*

| `NAME` | Environment variable name
|===

=== Return Value

Returns variable value as string.

=== Examples

[source,lisp]
----
(rust-env-var "PATH")     ; => "/usr/bin:/bin:..."
(rust-env-var "HOME")     ; => "/home/user"
(rust-env-var "USER")     ; => "username"
(rust-env-var "SHELL")    ; => "/bin/bash"
----

=== Common Environment Variables

[cols="1,3", options="header"]
|===
| Variable | Description

| `PATH` | System executable search path
| `HOME` | User home directory
| `USER` | Current username
| `SHELL` | Current shell
| `LANG` | System language
| `PWD` | Present working directory
| `OLDPWD` | Previous working directory
|===

== rust-env-vars

Lists all environment variables.

=== Syntax

[source,lisp]
----
(rust-env-vars)
----

=== Parameters

None.

=== Return Value

Returns list of environment variables as strings in format "NAME=VALUE".

=== Examples

[source,lisp]
----
(rust-env-vars)  ; => ["PATH=/...", "HOME=/...", ...]
----

== rust-env-set

Sets an environment variable.

=== Syntax

[source,lisp]
----
(rust-env-set "NAME" "VALUE")
----

=== Parameters

[cols="1,3", frame=none]
|===
| *Parameter* | *Description*

| `NAME` | Environment variable name
| `VALUE` | Value to set
|===

=== Return Value

Returns nil.

=== Examples

[source,lisp]
----
(rust-env-set "MY_VAR" "hello")
(rust-env-set "PROJECT_NAME" (rust-path-filename (rust-env-current-dir)))
(rust-env-set "HOST_UID" (rust-process-output "id" "-u"))
----

=== Best Practices

1. Use descriptive variable names
2. Store computed values for reuse
3. Use consistent naming conventions

== Practical Examples

=== Project Setup

[source,lisp]
----
;; Set project-specific environment
(rust-env-set "PROJECT_NAME" (rust-path-filename (rust-env-current-dir)))
(rust-env-set "PROJECT_ROOT" (rust-env-current-dir))
(rust-env-set "CONFIG_PATH" (rust-path-join (rust-env-current-dir) "config"))

(print "Project: " (rust-env-var "PROJECT_NAME"))
(print "Root: " (rust-env-var "PROJECT_ROOT"))
----

=== User Information

[source,lisp]
----
;; Get user info
(print "User: " (rust-env-var "USER"))
(print "Home: " (rust-env-home-dir))
(print "Shell: " (rust-env-var "SHELL"))
----

=== Docker Environment

[source,lisp]
----
;; Set Docker environment
(rust-env-set "DOCKER_BUILDKIT" "1")
(rust-env-set "COMPOSE_PROJECT_NAME" (rust-path-filename (rust-env-current-dir)))
(rust-env-set "HOST_UID" (rust-process-output "id" "-u"))
(rust-env-set "HOST_GID" (rust-process-output "id" "-g"))
----

== Error Handling

Environment commands handle errors gracefully:

[source,lisp]
----
;; Non-existent variable returns empty string
(rust-env-var "NONEXISTENT")  ; => ""

;; Set overwrites existing value
(rust-env-set "MY_VAR" "old")
(rust-env-set "MY_VAR" "new")
(rust-env-var "MY_VAR")  ; => "new"
----

== Security Considerations

=== Sensitive Data

Be careful with sensitive environment variables:

[source,lisp]
----
;; Sensitive variables (auto-masked in debug)
(rust-env-var "DATABASE_PASSWORD")  ; Use carefully
(rust-env-var "API_KEY")            ; Use carefully
----

DPM automatically masks sensitive data in debug output, but still:

1. Never log sensitive values
2. Use secure storage for secrets
3. Audit who can access environment variables
