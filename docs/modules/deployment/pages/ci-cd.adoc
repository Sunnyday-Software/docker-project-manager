=== Commit Validation

Validates commit messages:

[source,yaml]
----
# .github/workflows/commit-validation.yml
name: Commit Validation

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  validate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Validate commit messages
        run: |
          # Validate conventional commits
          npx commitlint --from HEAD~1 --to HEAD
----

=== Security Audit

Runs security checks:

[source,yaml]
----
# .github/workflows/security-audit.yml
name: Security Audit

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Install cargo-deny
        run: cargo install cargo-deny
      - name: Security audit
        run: cargo deny check
----

=== Build and Test

Builds and tests code:

[source,yaml]
----
# .github/workflows/build.yml
name: Build

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  build:
    strategy:
      matrix:
        os: [ubuntu-latest, macos-latest, windows-latest]
    runs-on: ${{ matrix.os }}
    steps:
      - uses: actions/checkout@v4
      - name: Build
        run: cargo build
      - name: Test
        run: cargo test
----

== CD Pipeline

=== Release Workflow

Automated releases:

[source,yaml]
----
# .github/workflows/release.yml
name: Release

on:
  push:
    branches: [main]

jobs:
  release:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Semantic Release
        run: npx semantic-release
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
----

=== Multi-Platform Build

Builds for all platforms:

[source,yaml]
----
# .github/workflows/build-multiarch.yml
name: Multi-Platform Build

on:
  release:
    types: [published]

jobs:
  build:
    strategy:
      matrix:
        include:
          - os: ubuntu-latest
            target: x86_64-unknown-linux-musl
            binary: dpm-linux-x86_64
          - os: ubuntu-latest
            target: aarch64-unknown-linux-gnu
            binary: dpm-linux-arm64
          - os: macos-latest
            target: x86_64-apple-darwin
            binary: dpm-macos-x86_64
          - os: macos-latest
            target: aarch64-apple-darwin
            binary: dpm-macos-arm64
          - os: windows-latest
            target: x86_64-pc-windows-gnu
            binary: dpm-windows-x86_64.exe
    runs-on: ${{ matrix.os }}
    steps:
      - uses: actions/checkout@v4
      - name: Build
        run: cargo build --release --target ${{ matrix.target }}
      - name: Upload artifact
        uses: actions/upload-artifact@v4
        with:
          name: ${{ matrix.binary }}
          path: target/${{ matrix.target }}/release/dpm*
----

## Release Process

### Semantic Versioning

DPM uses semantic versioning:

[cols="1,2", frame=none]
|===
| *Type* | *Example*

| Major | 1.0.0 → 2.0.0
| Minor | 1.0.0 → 1.1.0
| Patch | 1.0.0 → 1.0.1
|===

### Conventional Commits

Commit messages determine version bumps:

[cols="1,1,2", options="header"]
|===
| Type | Version | Description

| `feat:` | Minor | New feature
| `fix:` | Patch | Bug fix
| `docs:` | None | Documentation
| `chore:` | None | Maintenance
| `BREAKING CHANGE:` | Major | Breaking change
|===

### Release Steps

1. **Commit**: Push to main
2. **CI**: Run all checks
3. **Semantic Release**: Determine version
4. **Build**: Build binaries
5. **GitHub Release**: Create release
6. **Changelog**: Update CHANGELOG.md
