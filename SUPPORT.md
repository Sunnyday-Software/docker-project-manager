# Support

## Getting Help

There are several ways to get help with Docker Project Manager:

### GitHub Issues

For bug reports and feature requests, please open a GitHub issue:

- **Bug Reports**: Use the bug report template
- **Feature Requests**: Use the feature request template
- **General Questions**: Use GitHub Discussions

### Documentation

Check our comprehensive documentation for:

- Installation guides
- Command reference
- Configuration options
- Troubleshooting

### Before Asking for Help

Please try these steps first:

1. Search existing issues and discussions
2. Check the documentation
3. Review examples in the docs folder
4. Search the wiki

## Issue Templates

We provide issue templates to help you submit effective reports:

- **Bug Report Template** - Include reproduction steps
- **Feature Request Template** - Describe the desired functionality

## Response Times

- **Critical Bugs**: Within 48 hours
- **Normal Issues**: Within 1 week
- **Feature Requests**: Within 2 weeks

## Community Support

Join our community for peer support:

- GitHub Discussions
- Community forums (link if available)

## Contributing

If you'd like to help others:

1. Answer questions in discussions
2. Review documentation
3. Help triage issues
4. Contribute fixes

See [CONTRIBUTING.md](./CONTRIBUTING.md) for contribution guidelines.
